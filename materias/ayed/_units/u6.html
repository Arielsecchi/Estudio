6 Unidad 6: Patrones algorítmicos clásicos (contar, sumar, promediar, máximos/mínimos)

En las unidades anteriores aprendiste las piezas sueltas: variables y operadores (U2–U3), tomar decisiones con if (U4) y repetir con ciclos (U5). Esta unidad no trae piezas nuevas: trae recetas. Vas a ver que cuando combinás un ciclo con una variable que se va actualizando adentro, aparecen una y otra vez los mismos cinco o seis patrones: contar, sumar, promediar, buscar el máximo/mínimo y descomponer un número. Si los reconocés, la mitad de los ejercicios de la cátedra se resuelven casi en automático.

La idea central de toda esta unidad
Casi todos estos patrones tienen la misma forma de tres tiempos:

1) ANTES del ciclo → inicializo una variable "acumuladora" (un contador en 0, una suma en 0, un máximo en algún valor de arranque).
2) ADENTRO del ciclo → por cada dato que leo, actualizo esa variable (sumo 1, sumo el valor, comparo y me quedo con el mayor…).
3) DESPUÉS del ciclo → uso el resultado (lo muestro, lo divido para promediar, etc.).

Si entendés este esqueleto, todo lo demás son variantes.

Para los ejemplos vamos a usar muchísimo el ciclo con centinela (un valor especial que marca el fin de los datos), porque es el que más aparece en la guía. Recordá el molde de U5: leemos un valor, y mientras no sea el centinela, lo procesamos y volvemos a leer.

#include <iostream>
using namespace std;

int main() {
    int valor;

    cout << "Ingrese un valor (0 para terminar): ";
    cin >> valor;            // PRIMERA lectura, antes del while

    while (valor != 0) {        // 0 es el CENTINELA: corta el ciclo
        // ... acá adentro PROCESAMOS el valor ...

        cout << "Ingrese un valor (0 para terminar): ";
        cin >> valor;        // SIGUIENTE lectura, al final del cuerpo
    }

    return 0;
}
El centinela NO se procesa
Fijate que la primera lectura va antes del while y la siguiente al final del cuerpo. Esto se llama "lectura adelantada". Su gracia es que cuando entra el centinela (el 0), el while evalúa la condición, da falso y no ejecuta el cuerpo: el 0 nunca se cuenta ni se suma. Es el error más típico contar o sumar el valor que justamente indicaba "terminá".

Patrón 1 — Contar (contador condicional)

Contar significa responder a la pregunta "¿cuántos elementos cumplen tal condición?". Por ejemplo: cuántos valores fueron cero, cuántos negativos, cuántos alumnos aprobaron. La herramienta es una variable entera, el contador, que arranca en 0 y le sumamos 1 cada vez que el dato cumple la condición.

La receta de contar
• Antes: int cantidad = 0;  (siempre en cero, porque todavía no contamos nada).
• Adentro: if (condición) { cantidad = cantidad + 1; }
• Después: mostrás cantidad.

El cantidad = cantidad + 1; se puede escribir más corto como cantidad++;. Las dos formas hacen exactamente lo mismo: "tomá el valor que tenías, sumale uno y guardalo de nuevo".

Veámoslo con el ejercicio 1.a de la guía: dado un conjunto de valores enteros, calcular cuántos valores cero hubo. Usamos centinela. Ojo: el enunciado dice "valores enteros", así que el cero es un dato válido del conjunto; para no confundir el "cero que cuento" con el "cero que termina", muchos enunciados usan otro centinela, pero acá seguimos el espíritu de la guía contando los ceros que aparezcan antes de que el usuario decida cortar. Para que se vea limpio, usemos un centinela distinto, por ejemplo terminar cuando ingresan -9999:

#include <iostream>
using namespace std;

int main() {
    int valor;
    int cantidadCeros = 0;          // ANTES: arranca en 0

    cout << "Ingrese un valor (-9999 para terminar): ";
    cin >> valor;

    while (valor != -9999) {
        if (valor == 0) {           // ADENTRO: solo si es cero
            cantidadCeros++;        // ...sumo uno al contador
        }

        cout << "Ingrese un valor (-9999 para terminar): ";
        cin >> valor;
    }

    // DESPUES: ya recorrí todo, muestro el resultado
    cout << "Hubo " << cantidadCeros << " valores cero." << endl;
    return 0;
}
Traza con los datos: 4, 0, 7, 0, 0, -2, -9999
Seguimos "haciendo de computadora". cantidadCeros arranca en 0.

• Leo 4 → ¿es 0? No → contador sigue en 0.
• Leo 0 → ¿es 0? Sí → contador pasa a 1.
• Leo 7 → ¿es 0? No → sigue en 1.
• Leo 0 → ¿es 0? Sí → contador pasa a 2.
• Leo 0 → ¿es 0? Sí → contador pasa a 3.
• Leo -2 → ¿es 0? No → sigue en 3.
• Leo -9999 → es el centinela → corta el while (no se procesa).

Resultado en pantalla: Hubo 3 valores cero. ✓
Contar TODO vs. contar CON condición
Si querés contar cuántos datos hubo en total (sin condición), simplemente ponés el contador++; sin if, directamente adentro del ciclo: se suma uno por cada vuelta. Y si querés contar según varias categorías (como el ejercicio 6: cuántos ganan menos de $520, cuántos entre $520 y $780, etc.), usás varios contadores, cada uno con su if. La idea es siempre la misma, multiplicada.

Patrón 2 — Acumular / Sumar (sumatoria)

Sumar (o "acumular") responde a "¿cuánto suma el conjunto?" o "¿cuál es la suma de los que cumplen tal condición?". La diferencia con contar es sutil pero fundamental:

ContarSumar
Sumo siempre 1 (me importa cuántos son).Sumo el valor del dato (me importa cuánto valen juntos).
cantidad = cantidad + 1;suma = suma + valor;

La variable que va guardando la suma se llama acumulador, y también arranca en 0 (porque la suma de "nada" es cero, el elemento neutro de la suma).

Tomemos el ejercicio 1.c: la sumatoria de los valores negativos. Recorremos el conjunto y, cada vez que el valor es negativo, lo agregamos al acumulador:

#include <iostream>
using namespace std;

int main() {
    int valor;
    int sumaNegativos = 0;          // ANTES: acumulador en 0

    cout << "Ingrese un valor (0 para terminar): ";
    cin >> valor;

    while (valor != 0) {
        if (valor < 0) {            // ADENTRO: solo si es negativo
            sumaNegativos = sumaNegativos + valor;   // acumulo el valor
        }

        cout << "Ingrese un valor (0 para terminar): ";
        cin >> valor;
    }

    cout << "La suma de los negativos es: " << sumaNegativos << endl;
    return 0;
}
Traza con los datos: 5, -3, 8, -10, -2, 0
sumaNegativos arranca en 0.

• Leo 5 → ¿negativo? No → suma sigue en 0.
• Leo -3 → ¿negativo? Sí → suma = 0 + (−3) = −3.
• Leo 8 → ¿negativo? No → sigue en −3.
• Leo -10 → ¿negativo? Sí → suma = −3 + (−10) = −13.
• Leo -2 → ¿negativo? Sí → suma = −13 + (−2) = −15.
• Leo 0 → centinela → corta.

Resultado: La suma de los negativos es: -15 ✓
No inicializar el acumulador (o inicializarlo mal)
Si declarás int suma; sin el = 0, esa variable arranca con basura (un valor impredecible que quedó en la memoria). Tu suma quedaría contaminada con un número al azar. Siempre inicializá el acumulador en 0. (Para multiplicar/acumular un producto, en cambio, se arranca en 1, porque 1 es el neutro de la multiplicación.)

Patrón 3 — Promediar (y sus dos trampas)

El promedio es "suma dividida por cantidad". Es decir: combina los dos patrones anteriores. Necesitás llevar al mismo tiempo un acumulador (la suma) y un contador (cuántos elementos sumaste), y al final dividir uno por el otro.

Hagamos el ejercicio 1.b: el promedio de los valores positivos. Por cada positivo, lo sumo y además cuento uno:

#include <iostream>
using namespace std;

int main() {
    int valor;
    int sumaPositivos = 0;          // acumulador
    int cantPositivos = 0;          // contador

    cout << "Ingrese un valor (0 para terminar): ";
    cin >> valor;

    while (valor != 0) {
        if (valor > 0) {
            sumaPositivos = sumaPositivos + valor;   // sumo
            cantPositivos = cantPositivos + 1;       // y cuento
        }

        cout << "Ingrese un valor (0 para terminar): ";
        cin >> valor;
    }

    // DESPUES: ¿hubo positivos? Recién ahí divido.
    if (cantPositivos > 0) {
        float promedio = (float) sumaPositivos / cantPositivos;
        cout << "El promedio de positivos es: " << promedio << endl;
    } else {
        cout << "No hubo valores positivos." << endl;
    }

    return 0;
}

Mirá las dos cosas raras de ese final, porque son las dos trampas clásicas del promedio que la cátedra busca que reconozcas:

Trampa 1: división por cero
Si el conjunto no tuvo ningún positivo, cantPositivos vale 0. Hacer suma / 0 es una división por cero: matemáticamente indefinida, y en C++ con enteros provoca que el programa se rompa (crash). Por eso antes de dividir SIEMPRE preguntás if (cantPositivos > 0). Si la cantidad es 0, mostrás un mensaje ("no hubo positivos") en lugar de dividir. Olvidar este chequeo es uno de los errores que más puntos cuesta.
Trampa 2: división entera
En C++, si dividís dos enteros, el resultado es entero: la parte decimal se tira (no redondea, trunca). Por ejemplo 7 / 2 da 3, no 3.5. Entonces, si la suma es 7 y la cantidad 2, un promedio calculado como int te daría 3, ¡que está mal! La solución es que el cálculo se haga en punto flotante: declarás el resultado como float (o double) y casteás uno de los operandos con (float). Con (float) suma / cant, la suma se convierte a real, y entonces la división es real: 7.0 / 2 = 3.5. ✓
¿Qué es "castear"?
Castear es convertir un dato de un tipo a otro momentáneamente. (float) sumaPositivos le dice a C++: "tratá este entero como si fuera un número real para esta operación". Con que uno de los dos lados de la división sea real, C++ hace toda la división en real. Cuidado con esta trampa sutil: (float)(suma / cant) NO sirve — los paréntesis hacen que primero se divida entero (truncando) y recién después convierta. El casteo tiene que estar antes de la división: (float) suma / cant.

Patrón 4 — Máximos y mínimos

El problema es: tenés un conjunto de valores que se van leyendo de a uno (no los tenés todos juntos a la vista), y querés saber cuál es el mayor (o el menor). Como solo ves un valor por vez, la estrategia es llevar una variable max que guarde "el mayor que vi hasta ahora", e ir comparando cada nuevo dato contra ella.

La lógica de comparar contra "el mejor hasta ahora"
Adentro del ciclo, por cada valor leído:
• Máximo: if (valor > max) { max = valor; }  → "si este es más grande que el récord actual, es el nuevo récord".
• Mínimo: if (valor < min) { min = valor; }  → misma idea, al revés.

Es como ver una carrera: te quedás con "el que va primero por ahora", y solo lo cambiás si alguien lo pasa.

Toda la dificultad real está en una sola pregunta: ¿con qué valor arranca max? Porque la primera comparación necesita que max ya tenga algo adentro. Hay tres técnicas para resolver esto (las tres de las notas de clase). Vamos una por una.

Técnica A — Inicializar con un valor FUERA DEL DOMINIO

Si el enunciado te dice en qué rango están los datos (el "dominio"), podés arrancar max en un valor imposible de alcanzar por debajo, de modo que el primer dato real seguro lo supere y se convierta en el nuevo máximo.

Por ejemplo, si el enunciado dice que los valores son del dominio [0, +∞) (cero o positivos), arrancás el máximo en algo más chico que cualquier dato posible, como -1:

#include <iostream>
using namespace std;

int main() {
    int valor;
    int max = -1;       // mas chico que CUALQUIER dato del dominio [0, +inf)

    cout << "Ingrese un valor positivo (-9999 para terminar): ";
    cin >> valor;

    while (valor != -9999) {
        if (valor > max) {      // el primer dato (>= 0) siempre supera al -1
            max = valor;
        }

        cout << "Ingrese un valor positivo (-9999 para terminar): ";
        cin >> valor;
    }

    cout << "El maximo fue: " << max << endl;
    return 0;
}

Para un mínimo es al revés: arrancás en algo más grande que cualquier dato posible. Si el dominio fuese, digamos, notas de 0 a 10, podrías arrancar min = 11;.

La limitación de la técnica A
Esta técnica solo sirve si el enunciado define el dominio y te permite elegir un valor por fuera. Si los datos pueden ser cualquier entero (positivos y negativos sin límite), no existe un "más chico que todos" y esta técnica falla. Ese es justo el peligro de la próxima caja: arrancar un máximo en 0 "porque sí". Cuando no conocés el dominio, usá la técnica B o C.

Técnica B — Tomar el PRIMER elemento usando un contador de posición

La idea acá es: el primer dato que llega es, por definición, el máximo provisorio (es el único que viste, así que es el mayor hasta ahora). Para detectar "¿estoy en el primer dato?" usamos un contador de posición i que arranca en 1, y aprovechamos el operador OR (||):

#include <iostream>
using namespace std;

int main() {
    int valor;
    int max;            // NO la inicializo: el primer dato la define
    int i = 1;          // contador de posicion

    cout << "Ingrese un valor (0 para terminar): ";
    cin >> valor;

    while (valor != 0) {
        if (i == 1 || valor > max) {    // si es el PRIMERO, o si supera al max
            max = valor;
        }

        i = i + 1;                       // avanzo la posicion
        cout << "Ingrese un valor (0 para terminar): ";
        cin >> valor;
    }

    cout << "El maximo fue: " << max << endl;
    return 0;
}
Por qué funciona el i == 1 || valor > max
El || (OR) da verdadero si al menos una de las dos condiciones se cumple. En la primera vuelta, i == 1 es verdadero, así que entra al if y hace max = valor sin siquiera mirar valor > max (gracias a esto no usamos max antes de inicializarla). En las vueltas siguientes i ya no es 1, entonces lo único que decide es valor > max: la comparación normal. Esta técnica funciona con cualquier dominio, incluso negativos, porque no inventás ningún valor de arranque.

Técnica C — Tomar el primer elemento usando una BANDERA booleana

Es exactamente la misma idea que la B, pero en lugar de contar posiciones usamos una bandera (una variable bool) que dice "¿es la primera vez?". Arranca en true y la apagamos apenas procesamos el primer dato.

#include <iostream>
using namespace std;

int main() {
    int valor;
    int max;
    bool esLaPrimeraVez = true;     // bandera: arranca encendida

    cout << "Ingrese un valor (0 para terminar): ";
    cin >> valor;

    while (valor != 0) {
        if (esLaPrimeraVez || valor > max) {
            max = valor;
            esLaPrimeraVez = false;     // la apago: ya no es la primera vez
        }

        cout << "Ingrese un valor (0 para terminar): ";
        cin >> valor;
    }

    cout << "El maximo fue: " << max << endl;
    return 0;
}
Traza de la técnica C con: -5, -2, -9, -1, 0
Estos son todos negativos, justo el caso donde "arrancar en 0" fallaría. Veamos que con la bandera anda perfecto. max = (sin definir), esLaPrimeraVez = true.

• Leo -5 → ¿esLaPrimeraVez? Sí → entra: max = -5, bandera pasa a false.
• Leo -2 → ¿primera vez? No. ¿−2 > −5? Sí → max = -2.
• Leo -9 → ¿−9 > −2? No → max sigue en −2.
• Leo -1 → ¿−1 > −2? Sí → max = -1.
• Leo 0 → centinela → corta.

Resultado: El maximo fue: -1 ✓  (correcto: −1 es el mayor de los negativos).
El bug estrella: inicializar el máximo en 0 cuando hay negativos
Es tentador escribir int max = 0; y comparar directo. Pero si todos los datos son negativos (como −5, −2, −9, −1), ningún valor va a superar al 0, así que el if nunca entra y el programa informa que el máximo es… 0, ¡un valor que ni siquiera estaba en el conjunto! El 0 solo es un arranque seguro si el dominio garantiza que hay valores ≥ 0. Ante la duda, técnica B o C.

Variante — Máximo y cuántas veces se repite

Esta es una vuelta de tuerca muy pedida (el ejercicio 12 modificado de las notas): además del máximo, querés saber cuántas veces aparece ese máximo en el conjunto. La clave está en distinguir tres situaciones al comparar cada valor con el máximo actual:

CasoQué hacés
El valor es mayor que el máximoHay un nuevo récord: max = valor y reinicio el contador de repeticiones en 1 (esta es la primera vez que veo este nuevo máximo).
El valor es igual al máximoApareció otra vez el mismo récord: repeticiones++ (sumo una aparición).
El valor es menorNo hago nada: ni cambia el máximo ni el contador.
#include <iostream>
using namespace std;

int main() {
    int valor;
    int max;
    int repeticiones = 0;
    bool esLaPrimeraVez = true;

    cout << "Ingrese un valor (0 para terminar): ";
    cin >> valor;

    while (valor != 0) {
        if (esLaPrimeraVez || valor > max) {
            max = valor;            // nuevo maximo...
            repeticiones = 1;       // ...lo vi por PRIMERA vez (reinicio en 1)
            esLaPrimeraVez = false;
        } else if (valor == max) {
            repeticiones = repeticiones + 1;    // mismo maximo otra vez
        }

        cout << "Ingrese un valor (0 para terminar): ";
        cin >> valor;
    }

    cout << "El maximo es " << max
         << " y se repite " << repeticiones << " veces." << endl;
    return 0;
}
Traza con: 1 5 7 7 7 15 4 15 15 3 9 7 15 2 (centinela 0)
Vamos siguiendo max y repeticiones. Empieza con la bandera en true.

• 1 → primera vez → max=1, rep=1
• 5 → 5>1 → max=5, rep se reinicia a 1
• 7 → 7>5 → max=7, rep=1
• 7 → 7==7 → rep=2
• 7 → 7==7 → rep=3
• 15 → 15>7 → max=15, rep se reinicia a 1
• 4 → 4<15 → nada (max=15, rep=1)
• 15 → 15==15 → rep=2
• 15 → 15==15 → rep=3
• 3 → menor → nada
• 9 → menor → nada
• 7 → menor → nada
• 15 → 15==15 → rep=4
• 2 → menor → nada
• 0 → centinela → corta

Resultado
El maximo es 15 y se repite 4 veces.
En el conjunto, el 15 aparece en las posiciones del 6º, 8º, 9º y 13º dato → efectivamente 4 apariciones. (Si contás solo "a ojo" rápido podrías decir 3; por eso la traza paso a paso es tan importante: el cuarto 15 aparece tarde, después de varios números chicos.)
El error: reiniciar repeticiones a 0 (en vez de 1) al cambiar de máximo
Cuando encontrás un nuevo máximo, ese valor ya cuenta como una aparición: lo estás viendo en este preciso instante. Por eso se reinicia en 1, no en 0. Si lo ponés en 0, vas a terminar con una repetición de menos.

Variante — Posición relativa del máximo

Otra pregunta muy común (el ejercicio 10: imprimir el valor máximo y su posición relativa dentro del conjunto). "Posición relativa" significa el lugar que ocupa: si fue el 1º dato ingresado, el 5º, etc. La idea es llevar un contador de posición i, y cada vez que actualizás el máximo, guardar también en qué posición estabas.

El ejercicio 10 trabaja con valores positivos terminados con un negativo, así que el centinela es "valor negativo" (corta cuando valor < 0):

#include <iostream>
using namespace std;

int main() {
    int valor;
    int max;
    int posMax;             // posicion donde encontre el maximo
    int i = 1;              // posicion actual
    bool esLaPrimeraVez = true;

    cout << "Ingrese un valor positivo (negativo para terminar): ";
    cin >> valor;

    while (valor >= 0) {            // corta con el primer negativo
        if (esLaPrimeraVez || valor > max) {
            max = valor;
            posMax = i;             // me guardo la posicion del nuevo maximo
            esLaPrimeraVez = false;
        }

        i = i + 1;
        cout << "Ingrese un valor positivo (negativo para terminar): ";
        cin >> valor;
    }

    cout << "El maximo es " << max
         << " y esta en la posicion " << posMax << endl;
    return 0;
}
Traza con: 4 9 2 9 7 -1
• 4 (pos 1) → primera vez → max=4, posMax=1
• 9 (pos 2) → 9>4 → max=9, posMax=2
• 2 (pos 3) → 2<9 → nada
• 9 (pos 4) → 9>9 es falso → nada (se queda con la PRIMERA aparición)
• 7 (pos 5) → 7<9 → nada
• -1 → centinela → corta

Resultado: El maximo es 9 y esta en la posicion 2. ✓

Detalle fino: como usamos > estricto (no >=), si el máximo se repite nos quedamos con la posición de la primera vez que apareció. Si el enunciado pidiera la última, usarías >=.

Patrón 5 — Descomposición numérica (cambio de billetes)

Este patrón aparece en el ejercicio 14: dado un monto, calcular cuántos billetes de $100, $50, $20, $10, $5, $2 y $1 se necesitan, usando la mínima cantidad de billetes. La estrategia se llama "algoritmo voraz" (greedy): siempre usás la mayor cantidad posible del billete más grande, y con lo que sobra repetís bajando de denominación.

Las dos herramientas son operadores que ya viste en U3, pero acá lucen su verdadera utilidad:

División entera / y módulo %
• monto / 100 → cuántos billetes de 100 entran (la división entera tira los decimales: 5388/100 = 53).
• monto % 100 → cuánto sobra después de sacar esos billetes de 100 (el resto: 5388%100 = 88).

La receta por cada denominación es siempre la misma pareja:
billetes = resto / denominacion;   (cuántos uso)
resto = resto % denominacion;   (qué me queda para la próxima) 
#include <iostream>
using namespace std;

int main() {
    int monto;
    cout << "Ingrese el monto: ";
    cin >> monto;

    int b100 = monto / 100;     monto = monto % 100;
    int b50  = monto / 50;      monto = monto % 50;
    int b20  = monto / 20;      monto = monto % 20;
    int b10  = monto / 10;      monto = monto % 10;
    int b5   = monto / 5;       monto = monto % 5;
    int b2   = monto / 2;       monto = monto % 2;
    int b1   = monto;           // lo que queda son billetes de 1

    cout << "Billetes de 100: " << b100 << endl;
    cout << "Billetes de  50: " << b50  << endl;
    cout << "Billetes de  20: " << b20  << endl;
    cout << "Billetes de  10: " << b10  << endl;
    cout << "Billetes de   5: " << b5   << endl;
    cout << "Billetes de   2: " << b2   << endl;
    cout << "Billetes de   1: " << b1   << endl;
    return 0;
}
Traza completa con $5388
Arrancamos con monto = 5388 y vamos "gastando" el monto denominación por denominación:

• $100: 5388 / 100 = 53 billetes. Resto: 5388 % 100 = 88.
• $50: 88 / 50 = 1 billete. Resto: 88 % 50 = 38.
• $20: 38 / 20 = 1 billete. Resto: 38 % 20 = 18.
• $10: 18 / 10 = 1 billete. Resto: 18 % 10 = 8.
• $5: 8 / 5 = 1 billete. Resto: 8 % 5 = 3.
• $2: 3 / 2 = 1 billete. Resto: 3 % 2 = 1.
• $1: queda 1 billete.

Verificación
53·100 + 1·50 + 1·20 + 1·10 + 1·5 + 1·2 + 1·1 = 5300 + 50 + 20 + 10 + 5 + 2 + 1 = 5388 ✓
Total de billetes: 53 + 1 + 1 + 1 + 1 + 1 + 1 = 59 billetes, la mínima cantidad posible.
Detalle clave: por qué reutilizamos monto
Fijate que después de cada paso hacemos monto = monto % denominacion;. Así monto deja de ser el total original y pasa a ser "lo que falta por cambiar". El paso siguiente trabaja sobre ese resto, no sobre el monto entero. Si te olvidás de actualizar el resto y siempre dividís el monto original, te dan cantidades disparatadas. (El ejercicio 14 completo pide hacer esto para un conjunto de sueldos terminado en cero — o sea: este bloque de billetes va adentro de un ciclo con centinela, acumulando los billetes de todos los sueldos.)

Patrón extra — Validación de entrada con do-while

Muchos enunciados exigen que un dato esté dentro de cierto rango (por ejemplo "ingresar N menor que 25", como en varios ejercicios de la guía). Si el usuario mete algo inválido, no querés seguir: querés volver a pedírselo hasta que esté bien. El ciclo ideal para esto es el do-while, porque pide el dato al menos una vez y repite mientras siga siendo inválido.

#include <iostream>
using namespace std;

int main() {
    int n;
    do {
        cout << "Ingrese N (entre 1 y 24): ";
        cin >> n;
    } while (n < 1 || n > 24);     // repite MIENTRAS el dato sea invalido

    cout << "Perfecto, N = " << n << endl;
    return 0;
}
Cómo leer la condición del do-while
La condición describe cuándo seguir pidiendo (cuándo el dato es malo), no cuándo está bien. n < 1 || n > 24 es verdadero si N se pasó por abajo o por arriba: en cualquiera de esos casos, vuelve a pedir. En cuanto el usuario mete un valor del 1 al 24, la condición da falso y el ciclo termina dejando un dato garantizado válido para el resto del programa.

Repaso de la unidad

Lo que tenés que llevarte
• Todos los patrones siguen el esqueleto inicializar (antes) → actualizar (adentro del ciclo) → usar (después).
• Contar: contador en 0; if (cond) contador++; (sumo 1).
• Sumar: acumulador en 0; suma = suma + valor; (sumo el valor).
• Promediar: suma / cantidad. Cuidado con dividir por cero (chequeá if (cant > 0)) y con la división entera (usá (float) antes de dividir).
• Máximo/mínimo: el problema real es la inicialización. Tres técnicas: (A) valor fuera del dominio, (B) primer elemento con contador i == 1 || ..., (C) primer elemento con bandera bool. Nunca arranques un máximo en 0 si puede haber negativos.
• Máximo + repeticiones: al subir el máximo, reiniciás repeticiones en 1; si es igual, sumás 1.
• Posición del máximo: guardás posMax = i cuando actualizás el máximo.
• Descomposición / billetes: por cada denominación, billetes = resto / denom; y resto = resto % denom;.
• Validar entrada: do { pedir } while (dato invalido);.
• El centinela nunca se procesa: por eso la lectura adelantada (una antes del ciclo, otra al final del cuerpo).
