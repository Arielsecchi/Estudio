1 Unidad 1: Introducción — algoritmos, datos y tu primer programa

Esta primera unidad arranca de cero absoluto: vas a entender qué es un algoritmo, qué son los datos, qué significa programar, y vas a escribir, entender línea por línea y correr tu primer programa en C++. No hace falta saber nada previo.

¿Qué es un algoritmo?

Un algoritmo es una secuencia finita de pasos, ordenados y bien definidos, que resuelven un problema. La idea clave es que si seguís esos pasos en el orden indicado, siempre llegás al mismo resultado para la misma entrada: el comportamiento es predecible.

No es algo exclusivo de las computadoras. Usás algoritmos todo el tiempo en la vida real, solo que no los llamás así.

Algoritmos de la vida cotidiana
Receta de cocina — "1) Calentar el agua. 2) Cuando hierve, echar los fideos. 3) Esperar 10 minutos. 4) Colar." Son pasos, en orden, que resuelven el problema "cocinar fideos".

Llegar a la facultad — "1) Tomar el 28. 2) Bajar en Medrano. 3) Caminar 2 cuadras." Si alguien sigue exactamente esos pasos, llega al mismo lugar.

El trabajo del programador es escribir estos "pasos" de forma tan precisa que hasta una máquina —que no entiende sobreentendidos ni "vos ya sabés"— pueda ejecutarlos sin equivocarse.
Propiedades de todo buen algoritmo
• Preciso: cada paso no deja lugar a dudas (nada de "agregar sal a gusto").
• Ordenado / definido: los pasos tienen un orden claro y conocés cuál sigue.
• Finito: termina en algún momento, después de una cantidad limitada de pasos.
• Determinístico: con la misma entrada produce siempre la misma salida.
• Tiene entrada (los datos con los que arranca, que pueden ser cero) y salida (el resultado).

¿Qué son los datos y qué es una estructura de datos?

Un dato es un valor que el programa manipula: el número 42, la palabra "Hola", el valor lógico verdadero. Los algoritmos no operan en el vacío: leen datos, los transforman y producen nuevos datos.

Una estructura de datos es la forma de organizar esos datos para poder usarlos cómodamente en el algoritmo. No es lo mismo tener 100 números sueltos que tenerlos ordenados en una "lista" donde podés acceder al elemento número 37 de una.

La ecuación que da nombre a la materia
Algoritmos + Estructuras de datos = Programas. Esta frase (del científico Niklaus Wirth) resume la materia: un programa útil combina buenos pasos (algoritmos) operando sobre datos bien organizados (estructuras de datos). Las primeras unidades se enfocan en los algoritmos; más adelante aparecen las estructuras (vectores, registros).

¿Qué significa "programar"? Lenguajes y compilación

La computadora, en el fondo, solo entiende lenguaje de máquina: ceros y unos. Escribir directamente en ceros y unos sería imposible para un humano. Por eso usamos lenguajes de programación de alto nivel —como C++— que se parecen más al inglés y a las matemáticas, y que después se traducen a lenguaje de máquina.

El texto que vos escribís se llama código fuente (un archivo de texto, en C++ con extensión .cpp). Pero ese texto no se puede ejecutar tal cual: hay que traducirlo.

C++ es un lenguaje COMPILADO
El camino de tu código a un programa que corre es:

código fuente (programa.cpp) → COMPILADOR → ejecutable (un archivo que la máquina puede correr).

El compilador es un programa que lee todo tu .cpp, revisa que esté bien escrito (si hay errores de sintaxis, no compila y te avisa) y genera el ejecutable. Esto se hace una vez; después corrés el ejecutable las veces que quieras. (Otros lenguajes, como Python, son interpretados: se traducen línea por línea cada vez que corren. C++ no: primero compila, después ejecuta.)

Tu primer programa: "Hola mundo", línea por línea

Este es el programa más simple que muestra un texto en pantalla. Mirálo entero y después lo desarmamos:

#include <iostream>
using namespace std;

int main() {
    cout << "Hola mundo" << endl;
    return 0;
}

Cada parte cumple un rol concreto:

#include <iostream>

Es una directiva que le dice al compilador: "traé el conjunto de herramientas de entrada/salida". iostream significa input/output stream (flujo de entrada/salida). Gracias a esta línea podemos usar cout (mostrar en pantalla) y cin (leer del teclado). Sin ella, el programa no sabría qué es cout.

using namespace std;

Las herramientas estándar de C++ viven en un "espacio de nombres" llamado std (de standard). Esta línea nos permite escribir cout en lugar de std::cout cada vez. Es una comodidad: la vas a ver en casi todos los programas de la materia.

int main() { ... }

Es la función principal: el punto de arranque de todo programa en C++. Cuando ejecutás el programa, la computadora busca main y empieza a correr las líneas que están entre sus llaves { }, de arriba hacia abajo. Todo programa tiene exactamente un main.

Inicio y fin de tu programa
Comienzo: int main() {
Fin:     return 0; seguido de }

Todo lo que quieras que el programa haga va adentro de esas llaves.

cout << "Hola mundo" << endl;

Esta es la línea que hace algo visible: muestra el texto Hola mundo en pantalla y baja un renglón. La explicamos en detalle en la próxima sección.

return 0;

Le indica al sistema operativo que el programa terminó bien. El 0 significa "todo salió OK" (un número distinto se usaría para indicar que hubo un error). Como main está declarada como int (devuelve un entero), debe terminar devolviendo un número: por eso return 0;.

Mostrar por pantalla: cout y endl

cout (se lee "ci-aut", console output) es la salida estándar: la pantalla. Para mandarle algo se usa el operador <<, que podés imaginar como una flecha que empuja datos hacia la pantalla.

cout << "Hola mundo";        // muestra: Hola mundo
cout << 42;                  // muestra: 42
cout << "Edad: " << 20;      // muestra: Edad: 20

Fijate que podés encadenar varios << en una misma línea: cada uno empuja una cosa más a la pantalla, en orden, de izquierda a derecha. El texto entre comillas dobles ("...") se muestra tal cual; los números se muestran sin comillas.

endl y "\n": el salto de línea

endl (de end line) produce un salto de renglón: lo próximo que se muestre aparece en la línea de abajo. Es lo mismo que escribir "\n" dentro de un texto.

cout << "Linea 1" << endl;
cout << "Linea 2" << endl;

/* Muestra en pantalla:
   Linea 1
   Linea 2
*/
Error típico: olvidar los << entre cada cosa
Si querés mostrar un texto y un número juntos, cada elemento necesita su propia flecha:
✗ cout << "Edad: " 20;  → error, falta el << antes del 20.
✓ cout << "Edad: " << 20;

Comentarios: notas para humanos

Un comentario es texto que el compilador ignora por completo. Sirve para que vos (o quien lea el código) entienda qué hace cada parte. No afecta en nada lo que el programa ejecuta.

Hay dos formas:

// Comentario de UNA línea: desde las // hasta el final del renglón.

/* Comentario de
   VARIAS líneas: todo lo que está
   entre la barra-asterisco queda comentado. */

cout << "Hola" /* incluso en el medio de una linea */ << endl;
Usá comentarios desde el día uno
Comentar bien tu código es una costumbre profesional, no un adorno. Te ayuda a recordar qué pensabas y le facilita la corrección al docente. Pero comentá el porqué, no lo obvio: x++; // sumo 1 a x no aporta nada; x++; // cuento un alumno mas sí.

El punto y coma ; y los bloques { }

En C++, cada sentencia (cada instrucción completa) termina con un punto y coma ;. Es el delimitador de sentencias: le dice al compilador "esta orden terminó acá".

Las llaves { } sirven para agrupar varias sentencias en un bloque que se trata como una unidad (ya viste el bloque de main; más adelante los vas a usar en if, ciclos, funciones).

El error número uno de quien empieza: olvidar el ;
Si olvidás un punto y coma, el compilador se confunde y tira un error que muchas veces apunta a la línea siguiente (porque sigue leyendo esperando que la sentencia anterior termine). Ante un error raro de compilación, lo primero que conviene revisar es si falta un ; en la línea de arriba.

¿Cómo corro mi programa?

En la materia se trabaja típicamente con un editor como Visual Studio Code + un compilador de C++ (como g++, de MinGW). El flujo es siempre el mismo:

PasoQué pasa
1. Escribís el códigoGuardás el archivo .cpp (código fuente).
2. CompilásEl compilador traduce y, si no hay errores, genera el ejecutable. Si hay errores, los corregís y volvés a compilar.
3. EjecutásCorrés el ejecutable. El programa empieza en main y ejecuta las líneas de arriba hacia abajo.
La regla mental más importante para empezar
Salvo que una estructura de control diga lo contrario (lo verás en las próximas unidades), el programa se ejecuta secuencialmente, de arriba hacia abajo, una sentencia a la vez. Cuando leas un programa, "hacé de computadora": seguí las líneas en orden imaginando qué va pasando.

Repaso de la unidad

Lo que tenés que llevarte
• Un algoritmo son pasos finitos, ordenados y precisos que resuelven un problema.
• Un dato es un valor; una estructura de datos es la forma de organizarlo.
• C++ es compilado: código fuente .cpp → compilador → ejecutable.
• Todo programa arranca en int main() y termina con return 0;.
• #include <iostream> habilita cout/cin; using namespace std; evita escribir std::.
• Se muestra en pantalla con cout << ... ; y se salta renglón con endl.
• Cada sentencia termina en ; y los bloques se agrupan con { }.
• El programa se ejecuta de arriba hacia abajo.
