2 Unidad 2: Variables y tipos de datos

En la unidad anterior tu programa solo mostraba textos fijos. En esta unidad vas a aprender a guardar datos en la memoria de la computadora para poder usarlos, modificarlos y mostrarlos: eso son las variables. También vas a ver de qué tipos pueden ser esos datos (números enteros, decimales, caracteres, textos, valores de verdadero/falso) y cómo leer un dato que el usuario escribe por teclado. Seguimos de cero: cada término nuevo lo definimos antes de usarlo.

¿Qué es una variable?

Una variable es un espacio en la memoria de la computadora donde tu programa guarda un dato para usarlo más tarde. Pensala como una cajita con una etiqueta: la etiqueta es el nombre que vos le ponés, y adentro de la cajita hay un valor que podés mirar o cambiar.

¿Por qué se llama "variable"? Porque su contenido puede variar mientras el programa corre: hoy la cajita guarda un 10, dos líneas después puede guardar un 27. Lo que no cambia es su nombre ni el tipo de dato que puede guardar.

Las 3 componentes de toda variable
Cada variable que creás tiene siempre estas tres cosas:

• IDENTIFICADOR — el nombre con el que la llamás. Ej: edad, cantidadDeAlumnos. Es la "etiqueta" de la cajita.
• VALOR — el dato que guarda adentro en este momento. Ej: 20.
• TIPO DE DATO asociado — qué clase de dato puede guardar: un número entero, un decimal, una letra, un texto... Lo elegís vos al crearla y ya no cambia.
La analogía de la cajita
Imaginá una cajita etiquetada edad que solo acepta números enteros y que adentro tiene un 20:

• IDENTIFICADOR → edad (lo que dice la etiqueta)
• VALOR → 20 (lo que hay adentro hoy)
• TIPO → número entero (lo que la cajita acepta guardar)

Mañana podés cambiar el contenido a 21, pero la etiqueta sigue diciendo edad y la cajita sigue aceptando solo enteros.

Las dos etapas de una variable: definición y asignación

Para usar una variable hay dos momentos bien distintos que tenés que separar en tu cabeza: primero la creás (definición) y después le ponés valores (asignación). Vamos una por una.

Etapa 1 — DEFINICIÓN (crear la variable)

Definir una variable es crear la cajita: reservar el espacio en memoria y decirle al compilador su nombre y su tipo. Se escribe así:

<tipo de dato> <nombre de la variable>;

// ejemplo real:
int x;

Esa línea se lee: "creá una variable llamada x que va a guardar números enteros (int)". Dos reglas clave sobre la definición:

• Se hace una sola vez por variable, antes de poder usarla. No tiene sentido (ni se permite) volver a definir la misma variable.

• Ni bien la definís y todavía no le pusiste un valor, la cajita no está vacía: tiene un valor BASURA, un número aleatorio e impredecible que quedó de antes en esa zona de memoria. Nunca confíes en ese valor.

Error típico: usar una variable recién definida (valor basura)
Apenas definís int x;, x NO vale 0: vale lo que haya quedado en esa posición de memoria (puede ser 32766, -4391, cualquier cosa). Si la mostrás o la usás en una cuenta sin haberle asignado nada antes, vas a obtener resultados aleatorios y distintos en cada ejecución. Regla de oro: nunca uses una variable que no inicializaste vos.

Etapa 2 — ASIGNACIÓN (ponerle un valor)

Asignar es guardar un valor adentro de la cajita que ya existe. Se usa el signo =, que en programación NO significa "es igual" sino "asigná" / "guardá":

<nombre de la variable> = <valor>;

// ejemplo real:
x = 10;

Eso se lee: "guardá el valor 10 dentro de x". A diferencia de la definición, la asignación se puede repetir todas las veces que quieras: cada nueva asignación pisa (reemplaza) el valor anterior.

El = es asignación, no igualdad
En x = 10; pensalo como una flecha hacia la izquierda: el valor va a la DERECHA y la variable que lo recibe va a la IZQUIERDA. El valor de la derecha "viaja" hacia la cajita de la izquierda.

Por eso x = 10; es válido (guardá 10 en x) pero 10 = x; NO tiene sentido: no podés guardar nada "dentro del número 10".
Una variable, varias asignaciones (traza paso a paso)
int x;        // DEFINICIÓN: existe x, pero adentro hay BASURA
x = 10;       // ASIGNACIÓN: ahora x vale 10
x = 25;       // ASIGNACIÓN: el 10 se pisa, ahora x vale 25
x = x + 5;    // ASIGNACIÓN: toma el valor actual (25), suma 5, guarda 30
Seguimos el contenido de la cajita x línea por línea:
• Tras int x; → x = basura
• Tras x = 10; → x = 10
• Tras x = 25; → x = 25
• Tras x = x + 5; → x = 30  (primero se calcula la derecha con el valor viejo: 25 + 5 = 30, y recién después se guarda en x)

El atajo: definición con inicialización

Casi siempre vas a querer darle un valor a la variable en el mismo momento de crearla, así nunca queda con basura. Eso se llama inicializar, y combina las dos etapas en una sola línea:

int x = 10;    // define x (entero) Y le guarda 10 de una

Es equivalente a hacer int x; y después x = 10;, pero más corto y más seguro (no pasás por el estado de basura). Es la forma que vas a usar la mayoría de las veces.

Reglas para nombrar variables (identificadores)

El identificador es el nombre de la variable. No podés ponerle cualquier cosa: C++ tiene reglas obligatorias (si no las cumplís, no compila) y además hay convenciones (buenas costumbres que no son obligatorias pero que todos siguen).

Reglas OBLIGATORIAS (si no, error de compilación)
• Puede tener letras (a–z, A–Z), dígitos (0–9) y el guion bajo _. Nada más.
• No puede empezar con un dígito. edad2 es válido; 2edad no.
• Sin espacios. cantidad alumnos es inválido; usá cantidadAlumnos o cantidad_alumnos.
• Sin tildes ni eñes ni símbolos (á, ñ, $, %...). Escribí numeroDNi­os sin la eñe, por ejemplo cantidadNenes.
• No puede ser una palabra reservada del lenguaje (como int, return, main).
C++ distingue MAYÚSCULAS de minúsculas (case sensitive)
Para C++, edad, Edad y EDAD son tres variables DISTINTAS. Si definís int edad; y después escribís Edad = 20;, el compilador te dice que Edad no existe. Cuidá siempre cómo escribís cada letra: este es uno de los errores más comunes al empezar.

Convención: camelCase y nombres descriptivos

La convención que se usa en la materia (y en gran parte del mundo C++) para nombres de varias palabras es camelCase: la primera palabra va en minúscula y cada palabra siguiente arranca con mayúscula, todo pegado, sin espacios ni guiones.

int cantidadDeAlumnosEnElCurso;   // camelCase
float promedioFinal;
string nombreDelUsuario;

Se llama así porque las mayúsculas en el medio parecen las jorobas de un camello. Además, elegí nombres descriptivos: que el nombre diga qué guarda la variable.

Un buen nombre se explica solo
Comparál: int c; vs int cantidadDeAlumnos;. Las dos funcionan, pero la segunda hace que tu código se lea como una frase y no tengas que adivinar qué es c. Nombres claros = menos errores y corrección más fácil. Evitá nombres de una sola letra salvo para cosas muy chiquitas y momentáneas.

Tipos de datos

El tipo de dato define qué clase de valor guarda la variable y, muy importante, cuánta memoria ocupa. La memoria se mide en bytes (un byte son 8 bits, es decir 8 ceros/unos). Cuantos más bytes, más grande es el rango de valores que entra. Vamos a recorrer todas las familias.

Numéricos enteros

Guardan números sin parte decimal (…, -2, -1, 0, 1, 2, …). Se diferencian por cuántos bytes ocupan, y por lo tanto por cuán grandes pueden ser:

TipoTamañoPara qué
char1 byteEnteros muy chicos (y también caracteres, ya lo vemos)
short int2 bytesEnteros chicos
int4 bytesEl entero "de uso general", el más usado
long int4 bytesEnteros grandes

En la práctica, mientras aprendés, casi siempre vas a usar int para los enteros.

signed vs unsigned: ¿admite negativos o no?

Cada tipo entero puede ser:

• signed (con signo): admite negativos y positivos. Es el comportamiento por defecto: si escribís int a secas, es signed.

• unsigned (sin signo): NO admite negativos, solo desde 0 hacia arriba. A cambio, como no "gasta" la mitad del rango en números negativos, duplica el máximo positivo que puede guardar.

El caso de unsigned short (sacado del código de la cátedra)
Un short int ocupa 2 bytes. Con signo llega hasta unos 32767. Pero sin signo (sin gastar rango en negativos) llega al doble, hasta 65535: 
unsigned short int x = 65535;   // máximo valor que entra en un short sin signo
Por eso unsigned conviene cuando sabés que el valor nunca va a ser negativo (una cantidad de personas, una edad) y querés aprovechar todo el rango positivo.

Numéricos decimales (de punto flotante)

Guardan números con parte decimal, como 1.5, 3.14159 o -0.001. (En C++ el separador decimal es el punto, no la coma.)

TipoPrecisión
floatDecimal simple (menos cifras exactas)
doubleDecimal de doble precisión (más cifras, el más usado)
long doubleDecimal de precisión extendida (el que más cifras guarda)
float numero_A = 1.5;     // un decimal simple
double pi = 3.14159;      // doble precisión

Booleano

El tipo bool (1 byte) guarda un valor de verdad: solo puede valer true (verdadero) o false (falso). Sirve para responder preguntas de sí/no (¿el usuario es mayor de edad?, ¿el número es par?). Lo vas a usar muchísimo cuando lleguen las decisiones (if).

bool vBooleanaA = true;
bool vBooleanaB = false;

Carácter: char con comilla SIMPLE

El tipo char (1 byte) guarda un único carácter: una letra, un dígito o un símbolo. El valor va siempre entre comillas SIMPLES ' ':

char letra = 'A';    // UN carácter, comilla simple
char signo = '$';
char digito = '7';   // ojo: esto es el CARÁCTER 7, no el número 7

Cadena de caracteres: string con comillas DOBLES

El tipo string guarda un texto: un conjunto de caracteres, de cualquier largo. El valor va siempre entre comillas DOBLES " ". (Ocupa 1 byte por cada carácter, más 1 byte extra de control.)

string saludo = "Hola mundo";    // un texto, comillas dobles
string nombre = "Adrian";
Error típico: confundir 'A' (char) con "A" (string)
Aunque parezcan lo mismo, son tipos distintos:
• 'A' con comilla simple → es un char, UN solo carácter.
• "A" con comillas dobles → es un string, un texto (que justo tiene un carácter).

Por eso char c = "A"; da error (le estás dando un texto a una cajita de un solo carácter) y char c = 'A'; es lo correcto. Regla simple: comilla simple para char, comillas dobles para string.

Un char en el fondo es un número (código ASCII)

Acá viene algo que sorprende a todos: la computadora no sabe de letras, solo de números. Cada carácter tiene asociado un número entero según una tabla estándar llamada ASCII. Por ejemplo, la letra 'A' es el número 65, la 'B' el 66, y así. Por eso un char "es" un número de 1 byte por dentro.

Esto significa que podés definir un char dándole directamente su número ASCII:

char y = 65;     // 65 es el código ASCII de 'A', así que y vale 'A'

¿Cómo veo el número que hay detrás de un carácter? Si hacés cout << letra; vas a ver la letra (A), porque cout sabe que es un char y lo muestra como carácter. Para ver el número hay dos trucos que usa la cátedra:

• El + adelante (+letra): ese + fuerza a que el char se trate como número entero, así cout muestra el código en lugar de la letra.

• printf("%d", letra): printf es otra forma de mostrar por pantalla; el %d significa "mostralo como número entero (decimal)", forzando también a ver el código.

Ver la letra y su código ASCII (programa de la cátedra)
#include <iostream>
using namespace std;

int main() {
    char letra = 'A';   // guarda la letra A (ASCII 65)
    char y = 65;        // guarda el código 65, que ES la letra A

    cout << "El valor de letra es: " << +letra << endl;  // el + muestra el NÚMERO
    cout << "El valor de y es: " << y << endl;            // sin +, muestra la LETRA

    printf("%d", letra);   // %d fuerza a mostrar el número: 65
    printf("%d", y);       // idem: 65

    return 0;
}
Salida en pantalla:
El valor de letra es: 65
El valor de y es: A
6565
Fijate la diferencia: con +letra aparece 65 (el número), y con y a secas aparece A (la letra). Los dos printf imprimen 65 pegados (no hay salto de línea entre ellos), por eso se ve 6565.

Leer un dato por teclado: cin

Hasta ahora vos ponías los valores en el código. Pero lo interesante es que el usuario escriba un dato mientras el programa corre. Para eso está cin (se lee "ci-in", de console input): la entrada estándar, o sea el teclado.

Se usa con el operador >>. Si en la unidad 1 viste que cout << empuja datos hacia la pantalla, acá la flecha apunta al revés: cin >> variable trae lo que se escribe en el teclado y lo mete dentro de la variable. La flecha apunta desde el teclado HACIA la variable.

<tipo de dato> <nombre variable>;   // primero defino la cajita
cin >> <nombre variable>;            // después leo el teclado y lo guardo ahí
Leer un entero y mostrarlo
#include <iostream>
using namespace std;

int main() {
    int x;                       // defino la cajita (todavía con basura)
    cout << "Ingresa un numero: ";
    cin >> x;                     // el usuario escribe; ese valor se guarda en x
    cout << "Ingresaste el " << x << endl;
    return 0;
}
Si el usuario escribe 7 y aprieta Enter, la pantalla muestra:
Ingresa un numero: 7
Ingresaste el 7
El cin >> x; frena el programa esperando que el usuario escriba algo y apriete Enter; recién ahí guarda el valor en x y sigue.
Las dos flechas, una al lado de la otra
• cout << x; → la flecha sale de x hacia la pantalla (MOSTRAR).
• cin >> x; → la flecha entra desde el teclado hacia x (LEER/GUARDAR).

Truco para no confundirlas: las flechas siempre apuntan en el sentido en que viaja el dato.

Errores típicos con variables

Elegir un tipo que no alcanza para el valor (overflow)
Cada tipo tiene un máximo. Si intentás guardar un valor más grande del que entra, el número "se desborda" (overflow) y obtenés un resultado incorrecto, no un error. Ejemplo: un unsigned short llega hasta 65535; si le guardás 70000, el valor da la vuelta y queda algo chiquito y sin sentido. Solución: elegí el tipo según el rango de valores que vas a manejar (ante la duda con enteros, usá int).
Los tres errores que más vas a cometer al principio
• Usar una variable sin inicializar → te trae un valor BASURA aleatorio.
• Confundir 'A' (char, comilla simple) con "A" (string, comillas dobles).
• Equivocarte con mayúsculas/minúsculas del nombre (Edad ≠ edad).

Si un programa "anda mal sin razón", revisá primero estas tres cosas.

Repaso de la unidad

Lo que tenés que llevarte
• Una variable es una cajita en memoria con 3 componentes: identificador (nombre), valor (dato) y tipo (qué clase de dato).
• Definir (int x;) crea la variable UNA vez; recién definida tiene valor basura. Asignar (x = 10;) le guarda un valor y se repite cuantas veces quieras.
• El = es asignación: valor a la derecha, variable a la izquierda. Podés inicializar al crear: int x = 10;.
• Nombres: letras, dígitos y _; no empiezan con dígito; sin espacios ni tildes; case sensitive; convención camelCase y descriptivos.
• Enteros: char(1), short int(2), int(4), long int(4). signed (por defecto, admite negativos) vs unsigned (sin negativos, duplica el máximo: unsigned short llega a 65535).
• Decimales: float, double, long double. Booleano: bool(1) → true/false.
• char(1) va con comilla simple 'A' y por dentro es un número (ASCII: 'A' = 65); string va con comillas dobles "texto". Para ver el número de un char: +letra o printf("%d", letra).
• Se lee del teclado con cin >> variable; (la flecha apunta hacia la variable).
